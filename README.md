# Notebooks de Aprendizado

Repositório com notebooks usados durante estudos de Python, análise de dados e IA.

## Conteúdo

### NumPy
- **NumPy_1.ipynb** - Fundamentos de NumPy, manipulação de arrays e operações com dados numéricos

### Pandas
- **Pandas_Conhecendo_a_Biblioteca.ipynb** - Introdução ao Pandas com análise exploratória de dados de imóveis para aluguel
- **Pandas_IO_Mod_4.ipynb** - Entrada e saída de dados (I/O) com Pandas, trabalhando com CSV

### LangChain & IA
- **LangChain Intro.ipynb** - Introdução ao LangChain com Google Gemini, RAG (Retrieval Augmented Generation) e processamento de PDFs
